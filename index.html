Parte 1 · Como uma máquina aprende

Prever o preço de um apartamento pelo tamanho

Temos 8 apartamentos: tamanho e preço.

preço ≈ a + b · tamanho

O computador precisa encontrar a e b.

É a reta de regressão (mínimos quadrados), usada em estatística e econometria. Vamos ver como a máquina chega nela.

Parte 1 · Como uma máquina aprende

O erro é uma função de duas variáveis

E(a,b)=1n∑i=1n(a+b·xi−yi)2

Para cada apartamento i: xi é o tamanho e yi o preço.

Cada par (a, b) é uma reta, e E diz o quanto ela erra.

E tem um único ponto de mínimo, que é a melhor reta. As curvas de nível são elipses em volta dele.

Parte 1 · Como uma máquina aprende

Como diminuir o erro

As derivadas parciais ∂E∂a e ∂E∂b dizem para que lado o erro sobe.

Então andamos um pouco no sentido contrário:

a←a−η∂E∂a      b←b−η∂E∂b

Em forma de vetor: (a, b) ← (a, b) − η∇E, com o gradiente ∇E = (∂E/∂a, ∂E/∂b). Ele aponta para onde E cresce mais rápido, então o passo vai no sentido oposto.

η é o tamanho do passo, chamado taxa de aprendizado.

Repetir muitas vezes. Isso se chama gradiente descendente.

a derivada

Parte 1 · Como uma máquina aprende

A mesma ideia no ChatGPT

A mesma ideia, com muito mais variáveis. O GPT-3 (2020) tem 175 bilhões de parâmetros.

O treinamento repete esse passo da ordem de cem mil vezes. Cada passo ajusta todos os parâmetros.

Escolher η continua decisivo: grande demais diverge, pequeno demais demora.

Treinar uma IA é minimizar uma função de muitas variáveis.

Parte 2 · Como o ChatGPT escreve

De notas a probabilidades

pi=eziez1+…+ezn

É uma função de várias variáveis: uma nota para cada token do vocabulário, 50.257 tokens (GPT-2).

∂pi∂zi=pi(1−pi)>0

∂pi∂zj=−pipj<0 para j ≠ i

Aumentar a nota de uma palavra aumenta a probabilidade dela e diminui a de todas as outras.

Parte 2 · Como o ChatGPT escreve

Demonstração 2: sorteando a próxima palavra

Escrever é uma recursão: a palavra nova é sorteada a partir da anterior. É uma equação em diferenças com sorteio.

–

zi = ln contagem(palavra → i)
pi=ezi/T/(ez1/T+…+ezn/T)

Com T baixo, o modelo quase sempre escolhe a palavra mais provável. Com T alto, o texto fica mais surpreendente.

O laço do ChatGPT é o mesmo: notas, probabilidades, sorteio, repetir. A diferença está nas notas: elas vêm de uma rede (o Transformer) que lê o texto que cabe na janela de contexto, não só a última palavra.

Parte 3 · Como a IA desenha

Uma imagem é um ponto

Uma imagem de 512 × 512 pixels é representada por 786.432 números, três por pixel.

Em geradores como o Stable Diffusion 3, gerar uma imagem é levar um ponto do ruído até uma imagem, seguindo setas:

dxdt=v(x,t)

Isso é uma equação diferencial. O v(x, t) é um campo de velocidades (um campo vetorial: uma seta em cada ponto). No treinamento seguimos as setas −∇E. Aqui seguimos as setas v.

dxdt=−k(x−x∗)  tem solução  x(t) = x∗ + (x0 − x∗) e−kt

Com passos cada vez menores, a equação em diferenças se aproxima de uma equação diferencial: (1 − 2η)τ/η → e−2τ quando η → 0.

Resumo

Treinar

minimizar uma função de várias variáveis seguindo o gradiente, passo a passo. Cada passo é uma equação em diferenças.

Escrever

calcular probabilidades com o softmax, uma função de várias variáveis, e sortear a próxima palavra. Repetir.

Desenhar

seguir as setas de uma equação diferencial, em passos do método de Euler.

Derivadas parciais, equações em diferenças e equações diferenciais: as três estão dentro dessas ferramentas.
